# 한셀 2024 `.cell` 파일 형식

> 작성: yoomin53 · 대상 버전: 한컴오피스 2024 한셀 (HCell.exe 13.0.0.711)
>
> 이 문서는 한셀이 저장한 파일과 공개 표준(ECMA-376)을 대조해 얻은 관찰 결과다.
> 확인 수준을 항목마다 표시한다.
>
> - **관측**: 한셀이 저장한 실제 파일에서 확인
> - **문자열**: `HncOOXML.dll` 의 문자열 테이블에 이름만 존재. 의미는 미확인
> - **심볼**: `HncOOXML.dll` 이 export 하는 C++ 인터페이스 이름·인자 타입에서 확인. 의미는 이름 기준
> - **바이너리**: REA/Ghidra 로 `HncOOXML.dll` 의 요소 등록표·열거형 변환표에서 확인한 이름과 값
> - **추정**: 이름이나 맥락으로 짐작. 검증 필요

## 1. 컨테이너

| 세대 | 컨테이너 | 시그니처 | rcell 지원 |
|---|---|---|---|
| 한셀 2014 이후 (2024 포함) | ZIP / OPC | `50 4B 03 04` | ✅ 읽기 |
| 한셀 2010 이하 | OLE2 복합 문서 | `D0 CF 11 E0 A1 B1 1A E1` | ✅ 읽기 ([레거시](cell-legacy.md)) |
| 암호 설정 문서 | OLE2: `EncryptionInfo` + `EncryptedPackage` (ECMA-376 표준 암호화 3.2/4.2, AES-128 ECB, SHA-1 50,000회) | `D0 CF 11 E0 …` | ✅ 읽기 (표준 암호화, Agile 은 아직) |

보호(시트·통합 문서 보호)가 걸린 문서를 한셀이 바이너리·레거시로 저장하면 패키지를 기본 암호
`VelvetSweatshop` 으로 암호화한다 (관측). rcell 은 암호를 주지 않으면 이 기본 암호로 연다.

한셀 2024 의 `.cell` 은 **xlsx 와 같은 OOXML SpreadsheetML 패키지**다. 파트 구성도 xlsx 와 같다.

```

docProps/core.xml
xl/workbook.xml
xl/_rels/workbook.xml.rels
xl/sharedStrings.xml
xl/styles.xml
xl/theme/theme1.xml
xl/worksheets/sheetN.xml
xl/worksheets/_rels/sheetN.xml.rels
xl/drawings/drawing0.xml    ← Excel 은 drawing1 부터, 한셀은 0 부터 번호를 매긴다 (관측)
```

### 2.1 한셀의 `.cell` 과 `.xlsx` 는 같은 형식이다

같은 내용을 한셀 2024 에서 `.cell` 과 `.xlsx` 로 저장해 파트별로 비교했다 (관측).
파트 구성이 같고 `.xlsx` 에도 `hs:` 확장과 `mc:AlternateContent` 가 그대로 들어간다.
구조상 차이는 **통합 문서 파트의 콘텐츠 타입 하나**다.

| 저장 형식 | `/xl/workbook.xml` 콘텐츠 타입 |
|---|---|
| `.cell` | `application/vnd.ms-excel.sheet.macroEnabled.main+xml` |
| `.xlsx` | `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet.main+xml` |

나머지 차이는 공유 문자열 순서(위 표)와 `absPath` 경로뿐이었다. 따라서 rcell 의 `.cell`
파서는 한셀이 만든 `.xlsx` 도 그대로 읽는다. 쓰기를 구현할 때는 개인정보 보호를 위해
`absPath` 를 기록하지 않는다.

**호환성 함정:** 접두사가 붙은 요소를 처리하지 못하는 단순 파서는 한셀 파일을 읽지 못한다.
rcell 은 모든 요소를 네임스페이스 URI 로 비교한다 (`src/xml.rs`).

## 4. `mc:AlternateContent` 로 감싼 스타일 (중요)

한셀은 `styles.xml` 의 `x:font`, `x:xf`, `x:dxf` 중 한컴 확장이 있는 항목을
**`mc:AlternateContent` 로 감싸서** 확장판(`mc:Choice Requires="hs"`)과
표준판(`mc:Fallback`)을 함께 저장한다 (관측).

```xml
<x:fonts>
  <x:font>…</x:font>                                  <!-- 글꼴 0 -->
  <mc:AlternateContent>                               <!-- 글꼴 1 -->
    <mc:Choice Requires="hs">
      <x:font hs:extension="1">
        <x:name val="맑은 고딕"/><x:sz val="10"/><x:u/>
        <hs:underlineShape val="solid"/>
        <hs:size val="100"/><hs:ratio val="100"/><hs:spacing val="0"/><hs:offset val="0"/>
      </x:font>
    </mc:Choice>
    <mc:Fallback>
      <x:font><x:name val="맑은 고딕"/><x:sz val="10"/><x:u/></x:font>
    </mc:Fallback>
  </mc:AlternateContent>
  <x:font>…</x:font>                                  <!-- 글꼴 2 -->
</x:fonts>
```

`mc:AlternateContent` 하나가 **항목 하나**로 세어진다. 이 래퍼를 건너뛰는 파서는
그 뒤의 모든 `fontId` / `s`(셀 서식 번호) 가 하나씩 밀려 엉뚱한 서식을 적용한다.
rcell 은 ECMA-376 Part 3 규칙대로 이해 가능한 첫 `mc:Choice` 를 고르고,
없으면 `mc:Fallback` 을 고른다 (`xml::resolve_alternate_content`).

## 5. 글꼴 확장 — `x:font hs:extension="1"`

한글 워드프로세서의 '글자 모양' 속성을 셀 글꼴에 더한 것으로 보인다.
값은 모두 자식 요소의 `val` 속성(색은 `rgb`)이다.

| 요소 | rcell 필드 | 의미 | 관측값 | 확인 |
|---|---|---|---|---|
| `hs:size` | `size` | 상대 크기 (%) | 100, 0(dxf) | 관측 |
| `hs:ratio` | `ratio` | 장평 (%) | 100, 0(dxf) | 관측 |
| `hs:spacing` | `spacing` | 자간 (%) | 0 | 관측 |
| `hs:offset` | `offset` | 글자 위치 (%) | 0 | 관측 |
| `hs:underlineType` | `underline_type` | 밑줄 위치 (1 = 아래로 추정) | 1 | 관측 |
| `hs:underlineShape` | `underline_shape` | 밑줄 모양 | `solid`(한 줄), `doubleslim`(두 줄) | 관측 |
| `hs:underlineColor` | `underline_color` | 밑줄 색 | rgb | 관측 |
| `hs:useFontSpace` | `use_font_space` | 글꼴에 어울리는 빈칸 | 0 | 관측 |
| `hs:strikeoutType` | `strikeout_type` | 취소선 종류 | 1 | 관측 |
| `hs:strikeoutShape` | `strikeout_shape` | 취소선 모양 | `solid` | 관측 |
| `hs:strikeoutColor` | `strikeout_color` | 취소선 색 | `ff000000` | 관측 |
| `hs:outlineType` | `outline_type` | 외곽선 | `solid` | 관측 |
| `hs:shadowType` | `shadow_type` | 그림자 종류 | `drop` | 관측 |
| `hs:shadowColor` | `shadow_color` | 그림자 색 | `ffc0c0c0` (기본) | 관측 |
| `hs:shadowOffsetX` / `Y` | `shadow_offset_*` | 그림자 거리 (%) | 10 / 10 (기본) | 관측 |
| `hs:shadeColor` | `shade_color` | 음영 색 | — | 문자열 |
| `hs:emboss` / `hs:engrave` | `emboss` / `engrave` | 양각 / 음각 | — | 문자열 |
| `hs:superscript` / `hs:subscript` | | 위첨자 / 아래첨자 (`x:vertAlign` 과 함께 기록) | 1 | 관측 |
| `hs:useKerning` | `use_kerning` | 커닝 | — | 문자열 |
| `hs:diacsymMark` | `diacsym_mark` | 강조점 | — | 문자열 |

조건부 서식의 `x:dxf` 안 글꼴에서는 `hs:size`/`hs:ratio` 가 `0` 으로 관측되었다.
'지정 안 함'을 뜻하는 것으로 **추정**한다.

한셀은 필요한 확장 요소만 쓴다 (관측). 그림자·외곽선·취소선·첨자만 설정한 글꼴에는
해당 요소만 있고 `hs:size`/`hs:ratio`/`hs:spacing`/`hs:offset` 이 없다. 밑줄을 설정한
글꼴에는 네 요소가 모두 기본값(100/100/0/0)으로 함께 기록되었다.

### 5.1 차분 실험 (COM 자동화)

한셀 COM 자동화(`HCell.Application`, Excel 호환 객체 모델)로 셀마다 Excel 표준 글꼴 속성을
하나씩 설정하고 `.cell` 로 저장해 비교했다 (한셀 13.0.0.711).

| Excel 속성 | 표준 요소 | 한컴 확장 |
|---|---|---|
| `Font.Shadow` | — | `shadowType=drop`, `shadowColor=ffc0c0c0`, `shadowOffsetX=10`, `shadowOffsetY=10` |
| `Font.OutlineFont` | — | `outlineType=solid` |
| `Font.Strikethrough` | `x:strike` | `strikeoutType=1`, `strikeoutShape=solid`, `strikeoutColor=ff000000` |
| `Font.Superscript` | `x:vertAlign=superscript` | `superscript=1` |
| `Font.Subscript` | `x:vertAlign=subscript` | `subscript=1` |
| `Font.Underline = 한 줄` | `x:u` | `underlineType=1`, `underlineShape=solid` |
| `Font.Underline = 두 줄` | `x:u val=double` | `underlineType=1`, `underlineShape=doubleslim` |
| `Font.Underline = 회계용 한 줄/두 줄` | `x:u` / `x:u val=double` | 일반 한 줄/두 줄과 같음 → **회계용 구분이 저장되지 않음** |

밑줄·취소선 모양 이름(`solid`, `doubleslim`)은 한글 문서(OWPML) 선 종류와 같은 계열이다.
`HncOOXML.dll` 문자열에 `dashdot`, `dashdotdot`, `longdash`, `slimthick`, `thickslim`,
`slimthickslim` 이 있어 나머지 모양도 같은 이름을 쓰는 것으로 **추정**한다.

## 6. 셀 서식 확장 — `x:xf hs:applyExtension="1"` / `hs:parashape`

```xml
<x:xf numFmtId="0" fontId="0" fillId="0" borderId="0" xfId="0" applyAlignment="1" hs:applyExtension="1">
  <x:alignment horizontal="center" vertical="center"/>
  <hs:parashape hs:lineSpacingType="betweenLines" hs:lineSpacing="75"
                hs:breakNonLatinWord="breakWord" hs:breakLatinWord="keepWord"
                hs:condense="0" hs:textAlignment="baseLine"/>
</x:xf>
```

값 타입은 `HncOOXML.dll` 이 export 하는 C++ 인터페이스 이름
(`OOXML::SPREADSHEET::CParashape::Get<속성>`)의 인자 타입에서 확인했다 (**심볼**).

| 속성 | 의미 | 타입 (심볼) | 관측값 | 확인 |
|---|---|---|---|---|
| `hs:lineSpacingType` | 줄 간격 종류 | 열거 `ST_LineSpacing` | `betweenLines` (후보 `atLeast`) | 관측 |
| `hs:lineSpacing` | 줄 간격 값 | `unsigned int` | 74, 75 | 관측 |
| `hs:prevSpacing` / `hs:nextSpacing` | 문단 위/아래 간격 | `unsigned int` | — | 심볼 |
| `hs:breakLatinWord` | 영어 단어 나눔 | 열거 `ST_LineBreak` | `keepWord` | 관측 |
| `hs:breakNonLatinWord` | 한글 단어 나눔 | 열거 `ST_LineBreak` | `breakWord` | 관측 |
| `hs:condense` | 최소 공백 (%) | `unsigned int` | 0 | 관측 |
| `hs:textAlignment` | 세로 정렬 기준 | 열거 `ST_TextAlignment` | `baseLine` | 관측 |
| `hs:fontLineHeight` | 글꼴에 어울리는 줄 높이 | `bool` | — | 심볼 |
| `hs:leftMargin` | 왼쪽 여백 | `unsigned int` | 들여쓰기 n단계 → `1134 × n` | 관측 |
| `hs:rightMargin` | 오른쪽 여백 | `unsigned int` | 오른쪽 정렬 + 들여쓰기 2 → `2268` | 관측 |
| `hs:indentation` | 첫 줄 들여쓰기(+)/내어쓰기(−) | `int` (부호 있음) | — | 심볼 |
| `hs:abstractNumId` / `hs:abstractNumType` | 문단 번호 | `unsigned int` | — | 심볼 |

여백 단위 1134 는 HWPUNIT(1/7200 인치)로 보면 정확히 4.0 mm 다. 한글 문서와 같은
HWPUNIT 를 쓰는 것으로 **추정**한다.

`x:xf` 의 자식 `hs:accountUnderline` 은 `CAccountUnderline::Getshape(ST_UnderlineValues&)` 로
보아 회계용 밑줄 모양을 담는다 (**심볼**). 단, COM 으로 회계용 밑줄을 설정했을 때는 기록되지 않았다.

`x:dxf` 에도 `hs:applyExtension="1"` 이 붙는다 (관측).

### 6.1 `hs:parashape` 가 기록되는 조건 (COM 차분 실험)

| Excel 정렬 속성 | 표준 `x:alignment` | `hs:parashape` |
|---|---|---|
| 기본 | `horizontal="general" vertical="center"` | 없음 |
| 가로 균등 분할 (`xlDistributed`) | `horizontal="distributed"` | 있음 |
| 가로 양쪽 맞춤 (`xlJustify`) | `horizontal="justify"` | 있음 |
| 들여쓰기 (`IndentLevel`) | `indent="n"` | 있음 + `leftMargin`/`rightMargin` |
| 오른쪽에서 왼쪽 (`ReadingOrder`) | `readingOrder="1"` | 있음 |
| 선택 영역 가운데, 세로 균등/양쪽, 회전, 세로 쓰기, 축소, 줄 바꿈 | 표준 속성만 | 없음 |

**한셀의 기본 세로 정렬은 `center`** 다 (Excel 은 `bottom`). 렌더러는 `vertical` 속성이
없을 때의 기본값을 작성 프로그램에 따라 달리 해야 한다.
`spreadsheet/9.0/Alignment` 네임스페이스는 이 실험들에서도 나타나지 않았다.

## 6.2 export 심볼로 확인한 한컴 확장 클래스

`HncOOXML.dll` 은 C++ 클래스 인터페이스를 이름으로 export 한다. 함수 본문이 아니라
**이름과 인자 타입만** 사용했다 (`OOXML::SPREADSHEET` 네임스페이스).

| 클래스 | 대응 요소 (추정) | 값 타입 |
|---|---|---|
| `CParashape` | `hs:parashape` | 위 표 |
| `CUnderlineProperty` | `hs:underlineType` | `ST_UnderlineValues` |
| `CUnderlineExProperty` | `hs:underlineShape` / `hs:strikeoutShape` | `ST_UnderlineShape` |
| `COutlineProperty` | `hs:outlineType` | `ST_OutlineType` |
| `CShadowProperty` | `hs:shadowType` | `ST_ShadowType` |
| `CDiacsymProperty` | `hs:diacsymMark` | `ST_DiacsymMark` |
| `CAccountUnderline` | `hs:accountUnderline` | `shape: ST_UnderlineValues` |
| `CHCLWordshop` | 글맵시(워드아트) 개체 | `text`, `fontName`, `fontSize`, `b`, `i`, `shapeIndex`, `templateIndex`, `macro` |
| `CExtension::SetLicense` | `hs:license` | — |
| `CCalcPr::GethclCalcId` | `calcPr/@hs:hclCalcId` | `unsigned int` |
| `CFont`, `CRPrElt` | 셀 글꼴, **공유 문자열 런 글꼴(`x:rPr`)** | `ratio`, `spacing`, `size`, `offset`, `shadow*`, `strikeout*`, `underline*`, `outlineType`, `emboss`, `engrave`, `superscript`, `subscript`, `useFontSpace`, `useKerning`, `shadeColor`, `diacsymMark` |

`CRPrElt` 에도 같은 setter 가 있으므로 **서식 있는 텍스트의 런마다 한컴 글꼴 확장이 붙을 수 있다**.
rcell 은 런 글꼴(`x:rPr`)도 같은 파서로 읽는다.

## 7. 기타 확장

## 8. 열거형 값 (바이너리 — 변환표)

`HncOOXML.dll` 은 열거형을 `{wchar_t* 이름, int 값}` 쌍 배열로 갖고,
`{타입 이름, 개수, 배열}` 등록부에서 타입 이름(`L"ST_ShadowType"`)으로 찾는다.
아래는 한셀 스프레드시트 등록부의 배열을 그대로 옮긴 값 목록이다. 정수는 배열 위치와 같다.
rcell 은 이 목록을 `src/vocab.rs` 에 두고 `rcell scan` 에서 목록 밖의 값을 경고한다.

| XML | 타입 | 값 (0부터) |
|---|---|---|
| `hs:lineSpacingType` | `ST_LineSpacing` | `percent`, `fixed`, `betweenLines`, `atLeast` |
| `hs:breakLatinWord`, `hs:breakNonLatinWord` | `ST_LineBreak` | `keepWord`, `breakWord` |
| `hs:textAlignment` | `ST_TextAlignment` | `baseLine`, `top`, `center`, `bottom` |
| `hs:underlineShape`, `hs:strikeoutShape` | `ST_UnderlineShape` | `solid`, `dash`, `dot`, `dashdot`, `dashdotdot`, `longdash`, `circle`, `doubleslim`, `slimthick`, `thickslim`, `slimthickslim` |
| `hs:shadowType` | `ST_ShadowType` | `none`, `drop`(비연속), `continuous`(연속) |
| `hs:outlineType` | `ST_OutlineType` | `none`, `solid`, `dot`, `thick`, `dash`, `dashdot`, `dashdotdt` ← 철자 원문 그대로 |
| `hs:diacsymMark` | `ST_DiacsymMark` | `none`, `dot_above`, `ring_above`, `tilde`, `caron`, `sideout`, `colon`, `grave_accent`, `acute_accent`, `circumflex_accent`, `macron`, `hook_above`, `dot_below` |
| `hs:accountUnderline/@shape` | `ST_UnderlineValues` | `single`, `double`, `singleAccounting`, `doubleAccounting`, `none` |

`hs:underlineType`, `hs:strikeoutType` 은 문자열 열거가 아니라 **정수**로 기록된다 (관측값 `1`).
`ST_LineSpacing` 네 값은 한글 '문단 모양'의 줄 간격 종류(글자에 따라 / 고정 값 / 여백만 지정 /
최소)와 순서가 같아 `percent`=글자에 따라, `betweenLines`=여백만 지정으로 **추정**한다.
이 경우 관측값 `lineSpacing="75"` 는 줄 사이 여백이며 단위는 미확인이다.

분석 근거: REA 6.7.0 + Ghidra 12.1.4 (`trace`/`xrefs`, Evidence `ev_fe0742dc…`),
`HncOOXML.dll` SHA-256 `8a5fb336…46c7`. 분석 산출물은 저장소에 넣지 않았다.

## 9. 한셀이 XML 을 읽고 다시 저장할 때 스스로 바꾸는 것 (관측)

같은 XML 문서를 한셀로 열어 그대로 다시 저장하면(`Workbook.Saved = False` 후 `SaveAs`, 아래 첫 항목) 다음이 바뀐다.
rcell 의 저장 검증은 이 변화를 빼기 위해 HCell(원본) 과 HCell(rcell(원본)) 을 비교한다
([reverse-engineering.md](../reverse-engineering.md) 7절).

| 대상 | 바뀌는 것 |
|---|---|
| 같은 형식 `SaveAs` | 바뀐 것이 없는 문서면 **다시 쓰지 않고 파일을 그대로 복사**한다 |
| 여백 (`pageMargins`) | 읽을 때 HWPUNIT(1/7200 인치)로 **자른다** — 정수 단위 바로 아래 값(f32 를 거친 `0.51152777…` = 3682.99… 단위)은 한 단위를 잃는다. 머리글·바닥글 여백은 저장할 때마다 한 단위씩 계속 줄어든다 (0.511805 → 0.511666 → 0.511527 …). rcell 은 그런 값을 0.01 단위 위로 쓴다 |
| 차등 서식 (`x:dxf`) | 테마·색인 색을 RGB 로 바꾸고, 표시 형식 번호를 4294967295 로 쓰고, 위/아래 첨자·들여쓰기·글꼴 이름·외곽선·그림자·대각선 테두리와 보호 값(`<x:protection/>` 만 남는다)을 버린다. 이중 회계 밑줄을 단일 회계로 쓰고(바이너리·레거시는 지킨다), 글꼴 크기를 정수 pt 로 자른다. 한컴 확장이 붙은 글꼴은 표준 자식이 없어도 남기고, 확장 없는 빈 글꼴은 버린다 |
| 셀 스타일 | 셀 서식이 쓰는 스타일과 표준 스타일만 쓴다 |
| 표 스타일 | 요소를 종류 번호 순으로 정렬하고 `size`·`pivot`·`table` 을 늘 쓴다. 사용자 정의 스타일이 없어도 `tableStyles` 를 쓴다 (`TableStyleMedium2`·`PivotStyleLight16`) |
| 문단 번호 | `x:abstractNums` 를 문단 모양에서 새로 만든다: 번호가 있는 문단 모양이 있으면 하나 (`abstractNumType="1" abstractNumId="0" startNum="0" lvlText="%5e1."`), 문단 모양은 모두 그 번호를 가리킨다 |
| 글꼴 외곽선 | `hs:outlineType` 이 있으면 `x:outline` 을 켠다 (그림자 종류는 `x:shadow` 를 켜지 않는다) |
| 줄 간격 | `hs:lineSpacingType="atLeast"` → `betweenLines` |
| 취소선 | 취소선 모양(`hs:soShape`)이 있으면 표준 취소선(`x:strike`)을 켠다 |
| 개요 | `outlinePr summaryRight="0"` 을 잃는다 (요약 행 위치는 남는다) |
| 인쇄 | `pageSetUpPr autoPageBreaks="0"` 을 잃는다. 머리글·바닥글에서 글꼴 코드가 없는 구역에 기본 글꼴(`&"맑은 고딕,Regular"`)을 넣는다 |
| 틀 | 나눈 창(고정 아님)의 활성 창 `bottomLeft` → `topLeft` |
| 그리기 | 앵커를 내부 절대 좌표에서 다시 계산해 오프셋이 1px 안팎 바뀌기도 한다 |
| 외부 연결 | 어떤 수식·이름도 쓰지 않는 연결을 버린다. 갱신 오류(`refreshError="1"`)인 연결을 가리키는 이름 참조 `[n]시트` 를 `[경로/파일]시트` 로 펼친다. 경로 없는 연결(`xlPathMissing`)과 갱신 오류 여부에 따라 `'[n]시트'!` 의 따옴표를 붙이거나 뗀다 |
| 문서 속성 | `lastModifiedBy`·`revision`·`modified` 를 새로 쓴다 |
