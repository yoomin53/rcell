# 한셀 화면 배치와 그리기 규칙

> 작성: yoomin53 · 대상 버전: 한컴오피스 2024 한셀 (HCell.exe 13.0.0.711), 96 dpi, 확대율 100%
>
> rcell 의 HTML 렌더러(`src/render*`, `src/chart_svg.rs`)가 따르는 한셀 화면 규칙. 모두 한셀 COM 값과 화면
> 갈무리를 rcell 이 만든 실험 문서와 대조해 얻은 관찰이다. 실험 문서는 저장소에 두지 않는다 (만드는 스크립트의
> 규칙만 적는다).

## 1. 측정 방법

| 도구 | 하는 일 |
|---|---|
| `tools/probe/geometry-oracle.ps1` | 한셀(COM)로 문서를 열어 열마다 `Width`·`Left`, 행마다 `Height`·`Top` 을 TSV 로 (`#dir` 줄 + 파일·시트·종류·번호·값) |
| `tests/render_geometry.rs` | 위 TSV(`RCELL_GEOMETRY_ORACLE`)와 `render::sheet_geometry` 를 비교 — 열 px(1/20 pt 반올림)·누적 왼쪽, 행 pt·누적 위 |
| `tools/probe/screen-capture.ps1` | 한셀 창을 확대율 100%·머리글 끔·A1 스크롤로 `PrintWindow` 갈무리, A1 자리(`PointsToScreenPixelsX/Y`)와 격자 영역 크기를 적는다 |
| `tools/probe/visual-diff.ps1` | rcell HTML(`--no-headers --fill WxH`)을 헤드리스 Edge 로 그려 한셀 갈무리의 A1 부터 픽셀 비교 — 다른 픽셀 %(채널 차 > 48), 잉크 겹침 %(한셀의 어두운 픽셀 중 rcell ±1px 안에 어두운 픽셀이 있는 비율) |

화면 복사(`CopyFromScreen`)와 `PrintWindow` 갈무리는 같다 (데이터 막대 문서로 확인).

## 2. 열 너비

- 1글자 = 글꼴 0(글꼴 목록의 첫 글꼴 — 표준 스타일이 아니다)의 숫자 폭 K px (정수, 글꼴·크기 표 `metrics.rs`).
- 한셀 안의 열 너비 = 저장된 너비 w × K px (소수). Excel 처럼 여백을 더하거나 8px 배수로 맞추지 않는다.
- COM `Range.Width`·`Left` 는 이 값을 1/20 pt 로 반올림한 것. 화면은 열마다 반올림한 정수 px
  (머리글 구분선 대조: 32.5 → 33, 32.48 → 32, 12.5 → 13). 누적 위치도 열마다 반올림한 폭의 합.
- 기본 열 너비: `defaultColWidth` 가 소수면 그 값, 정수(또는 없음 = 8)면 기준 글자 수 → 한셀이 쓰는 너비
  (기준 8 은 K = 6…17 별 표, 그 밖은 Excel 식 여백 2·ceil(K/4)+1 을 더해 8px 배수로 올린 너비, `default_col_chars`).

## 3. 행 높이

- 높이는 1/20 pt 로 자른 pt. 화면은 행마다 round(twips / 15) px (13.125pt → 17px, 13.2pt → 18px).
- `customHeight` 가 있는 행만 저장된 `ht` 를 쓴다. 나머지 행(`ht` 만 있는 행, 한셀이 저장한 문서도)은 열 때
  다시 맞춘다. `sheetFormatPr/@defaultRowHeight` 도 `customHeight` 가 없으면 무시한다 (기본 높이 대조 실험).
- 맞춘 높이 = 그 행 모든 칸의 요구 높이 최대. 칸의 서식: 셀 레코드 → 행 서식 → 열 서식 → 서식 0. 값이 없는 칸도
  글꼴 높이를 낸다. 여러 행에 걸친 병합 칸은 빼고, 한 행 병합은 넣는다. 끝에 1/20 pt 로 자르고 409.5pt 가 위.
  - 글꼴 한 줄 높이: 글꼴 × 크기 표 (22 글꼴 × 24 크기, `metrics.rs`). 일부 크기는 1/40 pt 가 더 있다(`half` 비트).
  - 위·아래 테두리: 보통·중간 점선류 +7.5 twips, 굵게·이중 +15, 가는 선은 0.
  - 줄 바꿈: n 줄 = round(h1 + (n − 1)·L), L = (h5 − h1)/4 (1·2·5줄 높이를 잰 표).
  - 돌린 글자: 각도별 상자 높이 표 (0·15·30·45·60·90도), 세로 쓰기는 글자 수만큼.
  - 문단 모양(`hs:parashape`)의 위·아래 간격(1/100 pt), 상대 글꼴 크기(`hs:size`), 서식 있는 글 조각.
- 결과: 서식 파일 28종(XML·바이너리·레거시 84문서, 열 4362·행 11184) COM 대조 차이 0.

## 4. 칸 글자

- 왼쪽 맞춤 글자의 잉크는 칸 경계 다음 픽셀에서 2px 안쪽, 오른쪽 맞춤은 격자선 2px 앞 (보정 문서 갈무리 ±1px).
- 숫자: 일반 서식은 칸 폭 − 4px 에 맞춰 유효숫자를 줄이고(지수 표기 포함), 다른 서식은 넘치면 `#` 로 채운다.
  `#` 는 맞춤과 상관없이 왼쪽 2px 에서 시작한다 (DBNum 실험의 오른쪽 맞춤 숫자).
- 글자는 빈 이웃 칸으로 넘친다 (왼쪽·오른쪽·가운데). 값이 있는 칸이나 수식 칸에서 멈추고, 지나간 칸의 세로
  격자선·테두리만 지운다 (위·아래 선은 남는다).
- 줄 바꿈·양쪽 맞춤·균등 분할, 줄여 맞춤, 채움, 회전(1–90 반시계, 91–180 시계), 세로 쓰기(255), 들여쓰기 1 = 1134/7200 in.

## 5. 테두리·채우기

- 격자선 #D9D9D9 는 칸의 오른쪽·아래 끝 픽셀. 채운 칸은 격자선 자리까지 덮는다.
- 테두리는 칸 경계 픽셀에 SVG 로 (선 종류 13가지의 굵기·점선 무늬는 갈무리와 픽셀 단위로 같다, `paint.rs`),
  대각선 포함. 병합 칸은 왼쪽 위 칸의 위·왼쪽, 오른쪽 위 칸의 오른쪽, 왼쪽 아래 칸의 아래.
- 무늬 채우기 18종(8×8 픽셀 무늬), 그라데이션 채우기(선형 각도·경로).

## 6. 차트

차트 갈무리(craft-charts 15개 + 2차 실험)에서 잰 한셀 기본값 (`chart_svg.rs`):

- 틀 #868686 1px, 바탕 흰색. 그리기 개체 자리는 x−2·y−1 에서 폭·높이 +1.
- 축·눈금 #868686 1px, 눈금은 바깥 5px. 글자 검정 9pt, 제목 14pt 굵게. 계열 색은 테마 강조 1–6, 7번째부터 밝기 단계.
- 안쪽 여백: 왼쪽 12.5px(값 레이블 잉크가 틀 +13), 오른쪽 8, 위 16, 아래 16. 값 레이블 오른쪽 끝 → 축 14px,
  숫자 폭은 0.5em (9pt 에 6px — 100 이 70 보다 6px 넓다). 항목 레이블 가운데는 축 아래 22.5px.
- 자동 범위: 끝에 5% 여유를 둔 뒤 주 단위로 (60 → 70, 130 → 140 — 주 단위는 여유 없이 고른다), 3차원은 여유 없음
  (20~60 → 0~60). 0 에서 먼 값만 있으면(폭이 끝값의 1/6 이하) 0 을 넣지 않는다.
- 범례(오른쪽): 줄 18px, 표지 8px, 표지 → 글 5px, 글 끝 → 틀 12.5px, 그림 영역 → 표지 15px. 선 표지(꺾은선·분산형)는
  16px 선, 선 끝 → 글 1.5px, 글 끝 → 틀 11.5px, 그림 영역 → 선 9.5px. 아래 범례는 가운데가 틀 아래 17.5px,
  그림 영역을 28px 올린다.
- 가로 막대·분산형은 그림 영역이 10.5px 좁고(마지막 값 레이블의 반 + 4.5), 가로 막대의 그림 영역 위는 틀에서 8px.
- 원형: 지름 = 틀 높이 − 26 (위·아래 13px), 조각 경계선 없음.
- 3차원 막대: 2차원으로 그리고 앞면을 막대 폭의 (0.2, −0.12) 만큼 옮겨 윗면·옆면을 붙인다 — 깊이 (0.267, −0.233)×폭,
  윗면 = 앞면 색 × 0.72, 옆면 × 0.485 (#6182D6 → #465E9A·#2F3F68). 그림 영역은 깊이 자리만큼 줄인다
  (2차원 415×267 에서 왼쪽 +9, 오른쪽 −38, 위 +15, 아래 −2px).

## 7. 그리기 개체

- 자리 (앵커 대조 실험): 도형의 1px 선은 칸 경계보다 1px 왼쪽·위 픽셀 (선 가운데를 −0.5px 에), 그림은 1px 왼쪽·위.
- 미리 정의된 모양 90여 개와 `custGeom` (가이드 수식 `*/ +- +/ ?: abs at2 cat2 sat2 cos sin tan max min mod pin sqrt val`,
  `arcTo`, 경로 채우기 `darken`·`lighten` 등).
- 선 끝 화살표: 크기는 선 굵기 × (sm 2, med 3, lg 5) 인데 2pt 보다 가는 선은 2pt 로 본다 (1pt 선의 lg 삼각형 13px,
  3pt 선의 med 12px). 삼각형은 꼭짓점이 선 끝, 원·마름모는 가운데가 선 끝.
- 이음은 지정이 없으면 둥글다 (6pt 겹선 사각형). 겹선은 dbl 1:1:1, tri 1:1:2:1:1 (thickThin·thinThick 은 dbl 로 근사).
- 바깥 그림자: 거리·방향만큼 옮기고 흐림 반지름의 반을 표준 편차로, 색의 alpha 를 불투명도로.

## 8. 조건부 서식

### 데이터 막대

한셀은 데이터 막대를 **직각삼각형**으로 그린다: 시작(축) 쪽이 막대 높이 그대로이고 끝에서 0 (화면 복사로도 같다).
x14 확장 막대, 확장 없는 막대, 단색·그라데이션 모두 같은 모양 (x14 데이터 막대 실험 — 열 8개 × 값 −40…100, 행 높이
16·22·27·40·60px).

- 막대 영역은 칸 안쪽 [1, 1 + (w − 4)) px (w 는 격자선을 포함한 칸 폭), 위·아래 3px 씩 띄운다.
- 축: 자동이면 음수·양수가 섞일 때 0 의 자리(−min/(max − min)), 모두 음수면 오른쪽 끝, `middle` 은 가운데, `none` 은
  없음. 축 픽셀 = floor(1 + 영역 × 자리), 칸 높이 전체(아래 격자선 포함)에 2px 점·1px 틈 점선 (기본 검정).
- 막대는 축 다음 경계에서 시작. 양수는 축 → 영역 끝, 음수는 축 → 영역 시작 쪽으로 길이 비율만큼. 축이 없으면 영역 왼쪽에서
  (v − min)/(max − min). 0 은 막대 없음. 길이 비율 = 최소 + (최대 − 최소)·t (x14 기본 0·100, 확장 없으면 10·90).
- `autoMin`·`autoMax` 는 0 을 넣는다 (min(0, 최솟값), max(0, 최댓값)).
- 삼각형의 세로 변은 양수 막대면 왼쪽, 음수면 오른쪽. 오른쪽에서 왼쪽(`rightToLeft`)은 자리만 좌우로 뒤집고 모양은 그대로.
- 그라데이션은 세로 변의 색에서 끝의 흰색까지 (막대 길이에 맞춰). 테두리는 세로선이 축 다음 픽셀, 위·아래는 1px 바깥.
- 음수 색: `negativeBarColorSameAsPositive` 면 막대 색, 아니면 음수 채우기 색 — 없으면 확장 없는 막대는 검정, 확장이
  있으면 빨강. 음수 테두리도 같은 규칙.

### 아이콘

- 16×16 아이콘을 칸 왼쪽 3px, 세로 가운데 (행 안쪽 26px 이면 위 5px) — 아이콘 집합 20개 갈무리에서 모양·색을 땄다
  (빨강 #F24E4E·화살표 #F95151, 노랑 #FFD927, 초록 #5DBC77·화살표 #61BC66, 회색 #BFBFBF, 검정 #333333, 파랑 #266EB1).
- 번호 0 이 가장 낮은 단계. 사용자 지정 아이콘(`x14:cfIcon`)은 단계마다 (집합, 번호), `NoIcons` 는 아이콘 없음.
- 한셀은 **거꾸로(`reverse`)를 따르지 않는다** (본 구역·x14 구역 모두). 값 숨김(`showValue="0"`)은 따른다.

## 9. 메모

메모 실험 (기본, 채우기·선 색·2pt 선·그림자·가운데 맞춤, 먼 상자, 모양 속성 없는 VML):

- 모든 메모: 셀 오른쪽 위 빨간 삼각형 (6px).
- 보이는 메모: x:Anchor (열, px, 행, px) 둘이 상자. 선은 도형처럼 경계 1px 왼쪽·위 픽셀에 가운데 (0.75pt = 1px).
  그림자는 오른쪽·아래로 2px 검정. 글은 상자 안 왼쪽 2px·위 2px 부터, 9pt 돋움 한 줄 15px, 맞춤은 `x:TextHAlign`·
  `x:TextVAlign`. 상자는 셀 글자를 가린다.
- 화살표: 상자 왼쪽 위 모서리 → 셀 오른쪽 위 모서리(격자선 교차 픽셀), 1px 검정 선과 길이 9px·폭 7px 삼각형.
